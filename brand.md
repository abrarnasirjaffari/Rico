# Brand — Rico (OpenCode OC-1 × Zephium Workspace)

_Status: active_

## Design Direction
Architectural, calm, developer-grade financial & agentic browser workspace inspired by **OpenCode Desktop (`OC-1`)** and **Zephium (`Browse + Work`)**. Two-tier warm-neutral surface hierarchy where recessed chrome frames elevated active work panes, paired with live visible browser execution on the right split screen.

## Color Palette (OC-1 Light)
- **Recessed App Chrome (`--oc-bg-base`):** `#F8F7F7` — Titlebar (`40px`), collapsible left sidebar, inactive tab strip (`44px`), browser tab strip.
- **Active Workspace Surface (`--oc-bg-stronger`):** `#FCFCFC` / `#FFFFFF` — Center chat session column, right split-screen Browser/Review pane, active tab, composer card.
- **Subtle Surface Well (`--oc-surface-base`):** `#F1EFEF` — User message bubbles, count pills, subtle badges, hover states.
- **Hairline Structural Border (`--oc-border-weak`):** `#E6E4E3` — Primary `1px solid` structural dividers between panes, header, and tabs.
- **Control Border (`--oc-border-base`):** `#D6D3D1` — Inputs, buttons, composer card border.
- **Text Strong (`--oc-text-strong`):** `#1E1B1B` — Headings, active tabs, tool titles, primary body text.
- **Text Base (`--oc-text-base`):** `#5C5858` — Secondary labels, inactive tabs, tool subtitles.
- **Text Weak (`--oc-text-weak`):** `#8A8585` — Timestamps, placeholders, keyboard shortcuts.
- **Interactive Accent (`--oc-accent`):** `#034CFF` — Clickable browser links, active focus rings, live agent cursor & progress bar.
- **Semantic Status:** Emerald `#10B981` (verified/live), Amber `#F59E0B` (manual approval/takeover), Red `#EF4444` (blocked/anomaly).

## Typography
- **UI Sans:** `Inter` / `Geist` (`13px` chrome controls, `14px` chat & body, `-0.015em` heading tracking).
- **Technical Mono:** `Geist Mono` / `IBM Plex Mono` (`11px–12px` with `tabular-nums` for URLs, prices, FPS, latency, and tool traces).

## Voice & Copy
- Concise, direct, active voice. Show what the agent is doing on live pages in plain sight; ask before changing or paying anything.
